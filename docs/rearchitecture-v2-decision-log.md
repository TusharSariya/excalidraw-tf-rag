### Codex outside-voice folds (provisional)

1. Share-group **Python-client spike before P2**; fallback = classic consumer groups + Postgres claim rows.
2. Off-box restore is a P0b **acceptance gate** (CNPG PITR restored on a non-desktop machine).
3. P0 split into **P0a (GPU boundary) / P0b (platform services)**.
4. Postgres-as-queue instead of Kafka — **rejected** (settled user decision D1/D3).
5. SeaweedFS **storage torture gate**: kill -9 mid-write, disk-full, restic restore.
6. GPU exclusivity needs **host discipline** too (quota can't stop bare-metal CUDA loads).
7. **Rollback torture**: kill indexer during every rollback step; old run stays queryable.
8. Twin collapse deferred to P4 (see Issue 2).

### User directives (standing)

- **Nothing committed** — all changes stay in the working tree; commit/PR is the user's call.
- **V2 coexistence**: new code in `tools/pipeline-v2/`; existing packages additive-only; separate data planes; v1 never deleted until user retires it.
- Implement with Sonnet subagents, orchestrator monitors and shit-tests everything; production code quality; jobs may fail silently — verify outputs, don't trust reports.
- Terraform/OpenTofu included (D9).
